# 床炸法采集下界合金

## 前言

从 Minecraft Java 版 1.16
“下界更新”开始，下界合金取代了钻石，成为游戏内最强大的装备。与钻石装备不同，下界合金装备的制造需要使用下界合金锭、锻造模板和钻石装备在锻造台上升级制成。对于每
件装备，仅消耗一个下界合金锭，而下界合金锭需要四个下界合金碎片和四个金锭合成。下界合金碎片由远古残骸在熔炉中冶炼而成，因此每将一件装备从钻石制升级到下界合金制，
需要挖掘四个远古残骸。因此，如何安全、可靠地获取远古残骸是想要升级装备的玩家必须研讨的话题。
床炸法作为一种简单、高效率的挖掘方法，已经经过玩家社区的长期考验，特别适合普通玩家使用。本文将基于 Java 版 1.21.8
原版生存环境，简要叙述床炸法采集下界合金的步骤、作业流程和操作要领，帮助操作水平有限的玩家获取远古残骸，克服面对下界合金的畏难情绪。

## 一、远古残骸的生成概况

远古残骸在下界以团簇的形式生成。在 Java 版中，每个区块最多生成 2 个团簇，第一个团簇在 Y=8 到 Y=24 高度生成，第二个团簇在 Y=8 到
Y=119 高度生成。由于下界在 Y=60～100 的区间内大部分是空气，Y=30 附近还会生成大片的熔岩海，因此成功生成的远古残骸大部分落在 Y=16
附近。在区块边缘，还有可能出现由多个区块的远古残骸聚集形成的大型团簇。总体来说，每个区块中会生成 1.52
个远古残骸。实际操作时，能够暴露的数量要远小于这个值。
